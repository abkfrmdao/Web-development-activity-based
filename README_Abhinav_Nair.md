## 🚀 Projects Summary

### 1. Portfolio Website (Web Activity 1)

**Objective:** Create a personal portfolio webpage showcasing student information, technical skills, projects, and contact details.

#### Key Features
- Responsive navigation menu
- About Me section
- Technical Skills section
- Project showcase cards
- Contact information section
- Modern clean UI design

### 2. Sweet Delights Bakery Website (Web Activity 2)

**Objective:** Design an attractive bakery landing page displaying products, special offers, and business contact information.

#### Key Features
- Bakery-themed responsive layout
- Featured products section
- Seasonal offers banner
- Product pricing cards
- Contact and location details
- Easy navigation menu

### 3. NutriLife & Healthy Food Website (Web Activity 3)

**Objective:** Develop a healthy food and nutrition website providing meal plans, food categories, recipes, and wellness tips.

#### Key Features
- Healthy food categories section
- Nutritional meal plan cards
- Recipe information display
- Healthy lifestyle tips section
- Responsive content layout
- Clean educational interface
